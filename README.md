# ThyToxicGamer Command Center

Public, searchable command directory for the ThyToxicGamer community.

The site catalogs active commands from:

- Streamer.bot
- StreamElements
- Nightbot

## GitHub Pages

Publish from the `main` branch and the repository root (`/`). The site entry point is `index.html`.

## Graphics

- `assets/toxic-command-center-banner-v1.webp` is the optimized website banner.
- `assets/toxic-command-center-background-v1.webp` is the optimized page background.
- `assets/toxic-command-center-banner-concept-v1.png` is the full-quality banner and social-sharing image.

## Privacy

This repository contains public command descriptions only. Do not commit webhook URLs, API keys, access tokens, passwords, or private configuration exports.
